# 当前实现说明

本文维护源码职责；业务规则和开发要求见 [AGENT.md](../AGENT.md)，题面方案见 [项目答辩](project-solution.md)，验证范围见 [验收记录](acceptance.md)。不在本页重复追加开发过程日志。

## 1. 执行与模块

材料接入 → 保留原件及读取结果 → 主控提取 → 证据、金额、关联与历史核对 → 版本化修订与审核 → 题面 JSON。

简单任务批读后保存核验，复杂疑点才委派专家。LangChain create_agent 为主控，Deep Agents 提供子 Agent 与 Skill 渐进披露；Agent Server 管理运行与流式协议，计划按需使用原生 todos。不另建 Agent runner、固定财务 DAG 或 Skill 引擎。

| 模块 | 职责 |
| --- | --- |
| backend/agents/ | 主控、文档专家、账单专家与提示词 |
| backend/middleware/ | 原生扩展组合、会话意图、派发和结果边界 |
| backend/tools/ | 上下文、人工输入与包内函数绑定 |
| backend/skills/ | 八个业务包的规则、脚本、资源及独立测试 |
| backend/hooks/ | 十一类独立校验的注册、触发和裁决 |
| backend/harness/ | 共享计量、预算、派发身份和停止事实 |
| backend/extensions/、mcp/ | 固定能力快照、官方 MCP 连接与发现 |
| backend/infrastructure/ | 模型、仓储、资产与检查点生命周期 |
| backend/api/、config/ | HTTP 边界、配置模型与事务 |
| frontend/src/ | 页面、费用交互、证据预览和官方 SDK 订阅 |

业务算法只保留在所属 Skill，宿主不复制财务判断。[langgraph.json](../backend/langgraph.json) 注册图工厂 backend.agents:make_graph、HTTP 应用 backend.api:app 与官方检查点生命周期入口。扩展合同见 [Skill 与 Hook](skills-and-hooks.md)。

## 2. 材料与上下文

EML 保留正文、附件和父子关系；PDF/图片调用指定远程 OCR；Excel/Word保留单元格、公式和内容顺序，旧格式通过配置的 LibreOffice 转换。原件与派生血缘分别保存。

原件、原始 OCR 响应、提取结论分层存储。OCR 业务 JSON 不等于逐字全文，空费用列表不证明原件没有费用。引用必须可回读，页码、坐标、表格位置只能来自真实映射。

短材料包一次批读，默认阈值32,000字符；长材料先给清单，再检索和窗口扩读。原文外置，截断和未读范围可见；传输切片与语义分块分开，跨页保留两侧引用，重复表头、小计和总计不能重复计费。

当前主链路采用指定 OCR 与文本 LLM；VLM配置保留，按需视觉复核尚属增强方向，没有独立A/B结论。

## 3. 财务与版本

每项有效费用形成一条记录，无法确定的值为null。金额由Decimal核验；币种不从裸符号、语言或地区猜测，AR/AP由每次明确主体及真实债权债务关系判断。

常规新任务自动检索同主体、已完成且当前revision核验通过的历史记录，按四级规则匹配。唯一重复为NO_CHANGE，无匹配为CREATE，唯一匹配且有明确更新指令才UPDATE；多候选和冲突进入复核。

聊天和表单修订绑定费用ID及期望revision。只修改授权字段，继承其他事实，重算相关核验并使旧审批失效。正式导出再次检查当前版本、证据与全部必需Hook。

## 4. 恢复与成本

暂态错误有界重试；参数错返回具体反馈；误读定向补读；缺事实提出具体问题。复用已有正确字段、OCR响应和成功回执，从现有产物继续，不为局部缺口重跑整包。统一自动分级恢复与延时队列仍是完善方向。

主控、专家、重试共用真实请求计量。配置见 [runtime.yaml](../backend/config/runtime.yaml)，预算只是空转保护，不能替代业务完成路径。无进展时保留具体缺口与接续入口，合法修订提案可由宿主直接提交重算。

恢复可能重放节点，成功副作用须有回执及幂等身份；未知结果先核实。GaussDB保存业务版本，SQLite保存原生检查点，Agent Server dev元数据独立持久化，Redis支撑投影及缓存；多处存储没有跨库原子提交。详见 [恢复](recovery.md)。

## 5. 工作台与扩展

Vue/TypeScript/Vite与官方@langchain/vue管理工作台和线程订阅。列表读取摘要，详情读取完整费用与资产；聊天常驻，当前意图优先，未完成待办独立提醒。界面合同见 [界面说明](ui-design.md)。

配置发布固定能力快照，运行中任务不混用版本；启停在实际派发前复查，不能撤回已发请求。Skill发现、披露与工具绑定复用官方能力。

智能体操作调整前先查Docs MCP与API Reference MCP，核对安装版本；只有官方无法承担的具体领域职责才补最小实现。完整纪律在 [AGENT.md](../AGENT.md) §3.3、§3.5，专题和包内references保留查证依据。
