## CSS设计的具体对象

- 以一致的12/16/24px间距节奏建立布局；保留固定全局导航与各面板内操作。
- 4–8px圆角、细边框、受控的内侧亮边及少量阴影，构建清楚的层级；不再用巨大的彩色卡片、过多胶囊标签或装饰文案。
- 分段选择、输入框、图标按钮统一高度、边框和内边距。选中、悬停、按下、键盘聚焦均有明确差异。
- 表格采用细行分隔和所选行/所选单元格样式，数值列、状态及操作列保持对齐。
- 图表提示框单独设计背景、边缘、阴影、系列标记及两列数值对齐；图例、工具栏、范围选择器与外层UI遵循同一规范。
- 动效应在实际页面中验收，包括海面局部波动、导航和图标反馈、图表显示和交互状态。静态生成图不能证明CSS、动画或交互已完成。

## 图表的具体改动

- 主图将每日新增量按账单**当前**状态分组，使用堆叠柱或堆叠面积与总量线组合；标签明确创建日/当前状态，不冒充历史每日完成量。
- 同一图表内设计悬停选区、多系列数值提示、日均参考线和可拖动时间范围缩略轴。
- 辅助图在创建时段热力图、主体数量排行、精确状态分布中选择，采用同一配色和刻度规范，避免重复的圆环与进度条卡片。
- 热力图只基于创建时间；主体排行只基于账单数量。没有可用数据时给出真实空态，不编造时效、资金、准确率、航线或港口分布。
- 数值和日期均为合成演示数据。日新增示例10/18–10/24为10/18/12/23/19/26/20，总计128，日均18.3；当前状态示例113/8/3/4；主体示例64/40/24。
