# 航账全站海洋视觉改版

设计日期：2026-10-24。用户已批准第一张修订图并要求开始修改。现已在既有 Vue 3/TypeScript/Vite 工程实现海景页头、浅色侧栏、全站视觉 tokens、并排核账与助手及可关闭动效；以下方案生成记录保留为设计历史。

## 目标

面向航运账单处理人员，将工作总览、账单业务中心、待办复核、材料提交、账单详情、大屏及管理控制台统一成有海洋氛围、便于长时间核账的产品。大海动效与账单阅读区域分开，保留清晰的金额、币种、来源与人工处理入口。

## 全站布局

- 统一导航、字体、颜色、间距、表格、表单、对话框、空态、加载和错误状态。
- 工作总览：短海景横幅、开始处理材料入口、待办与最近账单；统计仅来自真实已有数据。
- 业务中心和待办：紧凑搜索筛选、统一表格和状态样式，各区域操作集中在所属标题栏。
- 材料提交：清晰的文件/邮件/链接入口、材料清单与一个主要提交操作，沿用现有能力。
- 账单详情：六字段费用表、所选费用依据和原件入口、常驻紧凑助手。待办保留醒目提醒，聊天消息顺序与历史滚动行为保持既有修复。
- 管理控制台：沿用全站设计体系，能力、经验库、Trace分区清楚，配置密度适合实际操作。
- 大屏：使用同一海洋视觉语言的深色变体；不新增虚构趋势或合计。

## 海洋动效

海景使用生成素材或已获授权的素材。总览使用短横幅，导航边缘和背景仅保留低对比海面光纹；账单、表格和原文使用稳定、不透明的阅读表面。后续实现缓慢的海景位移、轻微光影变化和短暂的界面进入过渡；不让页面和文字随海浪摇动。保留减少动态效果偏好，在窄屏降低装饰范围，不新增视频模型调用。

## 必须保留

- 固定的全局页头；面板操作放在正常布局中，无浮动操作工具栏。
- 桌面助手高度不超过480px，手机不超过440px；紧凑标题、输入区及内部滚动。
- 用户区与管理区分开；现有路由、上传、搜索、原件定位、修订、审批及导出继续可用。
- 后端保持关闭；本阶段不发起真实账单、OCR或财务模型请求，不跑全量测试。
- 生图凭据只在本地执行中使用，不进入源码、前端或Git。

## 三个独立视觉方向

1. `tide-workbench`：浅色海湾，深蓝窄侧栏、浅海景横幅，白色核账面板与右侧助手。
2. `deepsea-bridge`：深海驾驶舱，深蓝外壳、连续象牙白阅读表面，紧凑上下文与并排助手。
3. `coastal-flow`：通透海岸，横向导航、浅色纸面表格与行内证据，海景只占局部。

以上为文件名与方向说明。用户选择的编号以聊天中实际展示图片顺序为准。

每张图单独请求网站已验证的`/api/v1/images/generate`，随后按真实任务ID查询完成状态；不重复创建轮询中的生成任务。请求附带`synthetic-reference.jpg`，仅由项目已有的两张明确合成界面截图组成。各自的`.txt`保存完整提示词，`.json`保存无凭据、无临时图片链接的任务回执，`.jpeg`保存实际生成图。概念中的演示账单不是生产业务记录。

选定方案后的实现与验证记录见下文；效果图中的虚构业务字段和操作不能作为新增功能要求。

## 第一版选择与衔接修改

用户已选择聊天中第一张图，即`tide-workbench.jpeg`，并指出深色侧边栏与浅色主体风格割裂。本轮针对这张实际生成图继续修订，不重新探索三个方向。

- 海景横幅贯穿全宽，连接左上品牌区与右侧主工作区。
- 横幅下的侧栏改为浅雾绿，与浅灰绿主画布、白色阅读表面形成连续层次；统一文字、图标、选中项、分隔线和圆角。
- 保留六字段表、所选费用证据、常驻助手及现有全站导航；修订图进一步强调助手约450px高，避免整屏拉长。
- 动效计划：海景光影缓慢位移，导航选中及悬停约160–220ms反馈，面板轻量进入过渡。金额、原文、聊天正文不随海浪移动。
- 在全局页头提供“波光动效”开关；后续实现尊重系统减少动态效果偏好，关闭时海景保持静态，不影响业务可用性。

`tide-workbench-v2.txt`为修订提示词，生成请求实际附带`tide-workbench.jpeg`作为唯一图片参考；对应`.json`和`.jpeg`保存任务回执与修改效果图。该阶段先展示修订图，未修改应用；用户随后批准实施。

## 已实现

- 固定全宽海景页头、连续浅雾绿侧栏、统一灰白阅读面与海绿色操作状态。总览、业务中心、待办、提交页、管理端及弹窗共用主题；大屏采用同源海景的深色变体。
- 账单标题与摘要压紧；宽度至少1160px时，左侧费用/证据、右侧318px助手，较窄屏幕上下排列。默认六字段，置信度放在费用名旁；各面板操作仍位于本面板中。
- 海景使用网站生成的独立摄影素材，生产资产`frontend/src/assets/ocean-panorama.webp`为1600×240、88,952字节。原图、提示词与无凭据任务回执为`ocean-panorama.*`，并非整张效果图当背景。
- 海面28秒缓慢位移、18秒光影与240毫秒页面进入过渡；动效开关持久化，系统减少动态效果优先。金额、费用与聊天正文无循环位移动效。
- `frontend/tests/visual/ocean.html`使用真实App及组件和明确合成数据，在动态导入App前拦截API/线程请求，拒绝业务写入，不连接后端/模型/OCR。仅用于Vite开发预览，不进入生产构建。
- Vue类型检查及生产构建通过；14项既有消息顺序/账单状态定向离线检查通过。构建仍提示既有AgentPanel包超过500kB，不在此次视觉任务中改动SDK装配。

最终浏览器证据、布局测量、互动范围及已知验证边界以根目录`design-qa.md`为准。后端2024端口保持关闭，未跑全量或真实账单链路。
