## 已查明的问题

- `OceanBackdrop.vue` 只对一张静态海图做28秒缩放和平移，横向位移约1%，第二层18秒光影的透明度约0.025–0.1。当前浏览器的动效开关为on、系统减少动态效果为false，CSS动画确实在运行；问题是视觉变化过弱，不能称为实际海浪动画。
- 大屏主要图表只有很小的环图与72px高的新增柱条，五个相似指标卡片和大的空待办面板占据主要空间，用户难以迅速识别重点。
- 各级标题、辅助文字、指标值与操作之间差异不足；深色大屏多处低对比青灰文字削弱可读性。

## 选定后的落地范围

- 总览、业务列表、待办、提交、账单详情、管理页面统一使用选定的字体、图标、表格、表单和状态规范；不只修改配色。
- 标题采用明确字号层级；拉丁品牌/少量英文标题可使用真正的衬线斜体，中文正文、金额和币种维持易读的正体。金额使用等宽数字，不用全站斜体。
- 图标先匹配选定稿的图标体系，统一尺寸、粗细和选中状态。图标辅助识别，不能替代重要操作名称。
- 大屏只使用已有账单字段：按创建日期的新增量、当前状态构成、主体账单数与真实待办。时间范围切换必须真正改变图表输入；悬停提示和点击筛选可用。没有数据时显示明确空态，不能画一条假趋势；不将当前完成状态冒充某一天的历史完成量，不合并不同币种金额，不声称业务成功率或模型准确率。
- 主图表有坐标轴、刻度、图例、悬停定位和数据提示；用正式图表库实现，避免继续用简单CSS条代替图表。只在大屏/分析页懒加载，避免给聊天页增加不必要体积。
- 海景动效采用真实海图的局部波纹位移或可用的视频素材，2–3秒内能看到局部海面的变化；不能继续把轻微缩放当作海浪。财务表格、文字与聊天记录保持稳定。关闭、系统减少动态效果及后台标签暂停均有明确行为和静态回退。
- 交互包括导航选中、按钮按下与图标反馈、表格行高亮、抽屉/弹窗进入退出和图表呈现；通常160–240ms，动效关闭时无需等待装饰动画。
- 保留固定页头、面板内集中操作、常驻助手和未完成事项提醒。助手桌面上限480px、手机440px；保留原有订阅、消息顺序和滚动逻辑。
