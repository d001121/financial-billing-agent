# 航账 Harbor · 业务工作空间

前端使用 Vue 3、TypeScript、Vite 和官方 `@langchain/vue`，为用户提供工作总览、大屏、账单操作、待办复核和独立管理页面。日常操作围绕提交材料、核对结果、处理问题、确认导出展开；原生计划与执行回执按需查看。接口密钥由后端读取 `backend/.env`，前端不接入模型密钥。

## 直接使用

双击根目录 `start.cmd`，或在 `backend/` 运行 `start.cmd`，启动 Agent Server。构建产物已放在 `frontend/dist/`，后端在同一服务的 `/app/` 挂载页面。默认地址：`http://127.0.0.1:2024/app/`。

页面不需要单独启动 Node 服务。任务和能力数据来自后端，不填充假数据。

## 页面入口

| 页面 | 入口 | 用途 |
| --- | --- | --- |
| 工作总览 | `#/overview`，默认首页 | 查看真实任务统计、待办与最近动态，开始新的处理 |
| 大屏总控 | `#/screen` | 独立深色大屏展示状态、待办及主体分布，可直接打开任务 |
| 账单业务中心 | `#/tasks` | 搜索、状态与主体筛选、排序、分页，进入详情 |
| 待办复核 | `#/review` | 集中处理补充信息、人工请求和结果确认 |
| 提交新材料 | `#/new` | 在独立页面上传材料、指定主体并开始处理 |
| 账单详情 | `#/tasks/{task_id}` | 费用、置信度、原文定位、修订、确认与导出 |
| 管理中心 | `#/management` | 进入能力与连接、经验与规则 |
| 能力与连接 | `#/management/capabilities` | Agent、Skill、MCP、Hook和运行参数 |
| 经验与规则 | `#/management/improvements` | 反馈候选、评测、发布和回滚 |

地址使用Hash导航，可刷新或使用浏览器前进/后退。`#/tasks?status=review`等链接可以直接打开状态筛选；业务中心和待办页通过`KeepAlive`分别保留同次页面会话内的搜索、主体、排序与分页，从账单详情返回可继续原来的列表操作。整页重新加载只保留地址中的页面和状态筛选，不承诺保留局部输入。

界面采用深海军蓝、青绿与暖白，管理配置与日常操作分开。大屏展示真实任务数和任务创建量，不虚构业务地图、不累计不同币种金额；同步失败时保留旧快照并显示上次更新，没有首次数据时显示“—”。

## 本地开发

在 `frontend/` 执行：

```powershell
npm ci
npm run dev
```

Vite 默认监听 `127.0.0.1:5173`，端口占用时自动选择后续空闲端口，以终端实际输出为准。本机5173已有其他项目时，请勿停止它；也可显式运行 `npm run dev -- --port 5174`。

默认将 `/api`、`/threads`、`/assistants`、`/runs` 代理到 `http://127.0.0.1:2024`。后端改端口时，在启动 Vite 前设置：

```powershell
$env:BACKEND_URL = 'http://127.0.0.1:2024'
npm run dev
```

通常保持同源代理即可。单独部署时，构建前可设置 `VITE_API_BASE`（业务API前缀，默认 `/api`）和 `VITE_AGENT_URL`（官方Agent Server URL，默认页面同源）；跨域允许策略须同时由服务端正确配置。所有 `VITE_*` 变量都会进入浏览器构建，不能放服务密钥。

## 构建和检查

```powershell
npm run typecheck
npm run build
```

`build` 自带 `vue-tsc -b` 类型检查，产出 `dist/`。锁定版本记录在 `package-lock.json`。`npm run preview` 只预览构建资源；完整联调使用后端 `/app/` 或带代理的开发服务器。

## 主要操作

1. 在“提交新材料”填写本次记账主体，上传材料、导入题目样本或提供文件URL；需要时传入已有账单JSON。处理在后台进行，用户可离开页面稍后查看。
2. 在“业务中心”或“待办复核”查找任务，打开账单详情查看费用、置信度和问题，按需定位来源原文。待补充OCR链接与部分解析状态会明确展示，JSON与处理产物按需展开。
3. 在独立显示的原生中断卡片填写调用方回复；计划与执行日志折叠不隐藏人工请求。详情有thread时`AgentPanel`持续挂载，断开进度订阅不会取消服务端任务，重新连接会重新读取同一原生线程。
4. 修订金额、币种、费用名等字段，或删除、拆分费用、修改主体。服务端生成新Revision并重算校验。版本冲突时保留输入，核对最新内容后重新提交。
5. 明确确认当前Revision后，正式导出入口才启用；草稿导出单独标识。服务端仍重新执行必需校验，前端不以todo完成、模型文本或高分推断可导出；修订后需要重新确认。
6. 从管理中心进入“能力与连接”，编辑Agent、Skill、MCP、Hook与运行参数；保存携带配置版本，由服务端裁决生效范围。
7. 从管理中心进入“经验与规则”，将明确选择的费用映射保存为候选，运行固定样例评测、人工审核发布或回滚。发布仅影响后续新任务，当前任务保留原规则版本。

## 代码分工与同步

`src/pages/`保存总览、大屏、业务/待办列表和管理页面；`components/`保存材料表单、账单详情、原生Agent面板、证据预览和编辑弹窗。`utils/taskPresentation.ts`统一任务状态的展示分组、摘要计数和行动文案，不复制财务规则。`App.vue`负责Hash导航、列表缓存与摘要/详情读取，`styles/`集中维护视觉变量。

页面可见时每5秒读取任务摘要和health；只有打开账单详情才读取task与资产列表，避免总览遍历全部任务详情。完整费用与原文独立保存，摘要不能将它们覆盖。智能体流、todos、工具、子Agent和中断继续由官方Vue SDK订阅。

本次已通过LangChain Docs MCP复核join-rejoin，并用Reference MCP核对`useStream`和`disconnect`：同一`threadId`重挂载可重新订阅，`disconnect()`不取消服务端run。SDK仍为`@langchain/vue 1.2.5`，本次未修改原生执行或恢复实现。详细依据与分阶段验收见下方文档；旧工作台截图不作为新页面验收结果。

组件职责、API合同、原生SDK查证和验证边界见 `../docs/ui-design.md`。
